# ResInvest ERP

*Program stworzony przez Roesner Mateusz dla ResInvest Commodities.*

System ERP do obrotu i magazynowania biomasy drzewnej: zakupy, produkcja zrębki, sprzedaż, przesunięcia MM,
transport, inwentaryzacja, korekty, historia zmian, raporty miesięczne i roczne, kopie zapasowe, wielu użytkowników.

| Katalog | Zawartość |
|---|---|
| [`resinvest-erp/`](resinvest-erp/) | **ResInvest ERP 3.x** — wersja produkcyjna: program `ResInvest_ERP.html` (tryb OFFLINE) i serwer wielostanowiskowy (Node.js + SQLite), instalator Windows, dokumentacja, testy. Instrukcja: [`resinvest-erp/README.md`](resinvest-erp/README.md). |
| [`resinvest-erp-4/`](resinvest-erp-4/) | ResInvest ERP 4.0 — architektura docelowa (TypeScript, PostgreSQL, aplikacja Windows) w budowie. |
